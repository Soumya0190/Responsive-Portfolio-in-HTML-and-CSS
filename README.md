# Responsive-Portfolio-in-HTML-and-CSS
https://canvas.eee.uci.edu/courses/30017/assignments/599559


Here's how you can explain your **Responsive Portfolio in HTML and CSS** project using the **STAR method**:

---

### ✅ **S – Situation**
In my Web Development course, I was assigned to build a **responsive personal portfolio website** using only HTML and CSS. The purpose was to apply foundational web technologies to create a well-structured, visually appealing site that showcased my work and passed accessibility and validation standards.

---

### ✅ **T – Task**
The goal was to design and implement a **multi-page portfolio** that:
- Used semantic HTML elements.
- Included images with alt attributes, headings, links, and navigation.
- Demonstrated CSS styling for layout and readability.
- Included at least one advanced feature like a table, form, or media.
- Was responsive across desktop and mobile devices.
- Passed validation and followed good design principles.

---

### ✅ **A – Action**
To complete this assignment:
- I created several pages: a **home**, **about**, and **projects** page, all linked through a consistent **navigation bar**.
- Used **semantic tags** like `<header>`, `<main>`, `<aside>`, and `<footer>` for accessibility and structure.
- Applied **CSS styling** to improve aesthetics with Google Fonts, a color palette, and layout enhancements (margins, padding, flexbox).
- Embedded an **HTML5 video**, and added a **contact form** with input validation.
- Used **media queries** to ensure responsiveness across devices.
- Validated my HTML and CSS using W3C tools and ensured proper accessibility practices.

---

### ✅ **R – Result**
The final portfolio:
- Met all rubric criteria, including advanced features and validation checks.
- Looked consistent and professional on both desktop and mobile.
- Earned **full marks** for the assignment.
- Served as the foundation for my online presence and helped me better understand web design principles.
